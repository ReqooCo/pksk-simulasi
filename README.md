# PKSK Simulasi — 100 Set (Grouped)

## Struktur
10 folder utama, setiap folder mengandungi 10 set:
- SET 01-10
- SET 11-20
- SET 21-30
- SET 31-40
- SET 41-50
- SET 51-60
- SET 61-70
- SET 71-80
- SET 81-90
- SET 91-100

Setiap folder mempunyai:
- `data/` — 10 fail JSON
- `assets/visuals/` — semua rajah yang digunakan oleh set dalam kumpulan tersebut

## Algoritma
- Set 01 kekal sebagai master yang telah disemak.
- Set 02-100 menggunakan seed berbeza bagi setiap set.
- 10 tahap kesukaran.
- Variasi konteks, nombor, nama, tempat, aktiviti dan bentuk soalan.
- Bahagian B: 20 Matematik, 12 Sains, 10 BM, 10 English, 12 IQ/Logik, 5 Pengetahuan Am, 1 Penyelesaian Masalah.
- Kedudukan jawapan B diseimbangkan 18/18/17/17.
- Setiap B mempunyai explanation.
- Rajah matematik disimpan bersama kumpulan setnya.
- Pemeriksaan akhir: 100 set × 100 soalan = 10,000 soalan.
- Tiada teks soalan yang sama secara tepat antara 10,000 soalan yang dijana.

## Penting
Ini ialah produk latihan simulasi berasaskan struktur PKSK, bukan soalan rasmi KPM dan bukan jaminan ramalan soalan sebenar.
