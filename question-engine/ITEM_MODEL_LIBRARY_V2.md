# REQOO PKSK — ITEM MODEL LIBRARY V2

Purpose: define reusable reasoning recipes without reusing question wording or scenarios.

## Core model families

### MATHEMATICS
M01 Compare-after-transformation — compare quantities after percentage/ratio change.
M02 Constraint-budget — choose feasible plan under time/cost/capacity limits.
M03 Data-interpretation — infer from table/chart before calculating.
M04 Reverse-reasoning — infer original quantity from an outcome.
M05 Error-analysis — identify which calculation/assumption caused a result.
M06 Spatial-planning — combine dimensions, arrangement and constraints.
M07 Multi-condition optimisation — choose best option under competing constraints.

### SCIENCE
S01 Controlled-change prediction — predict effect when one variable changes.
S02 Evidence-evaluation — choose conclusion best supported by observations.
S03 Variable-identification — distinguish manipulated/responding/controlled variables.
S04 Mechanism-explanation — connect observation to scientific process.
S05 Experimental-design — choose a fair test or improve a flawed design.
S06 Classification-from-properties — infer category from observable properties.

### IQ / LOGIC
I01 Rule discovery — infer hidden rule from examples.
I02 Conditional deduction — combine if/then conditions.
I03 Ordering constraints — derive valid order from multiple clues.
I04 Classification — identify common principle rather than surface similarity.
I05 Code transformation — decode/encode using discovered rule.
I06 Spatial transformation — mentally rotate/reflect/compose structures.
I07 Hypothesis elimination — compare candidate explanations against evidence.

### EQ / SQ / SSQ
H01 Competing priorities — balance responsibility with another legitimate need.
H02 Perspective-taking — infer how different people may be affected.
H03 Repair-after-conflict — choose action that restores cooperation without avoiding accountability.
H04 Ethical trade-off — choose fair action when all options have costs.
H05 Leadership-under-constraint — coordinate people under time/resource pressure.
H06 Feedback-response — respond constructively to criticism while preserving standards.
H07 Group-decision — evaluate evidence, roles and minority views before deciding.

### BM / ENGLISH
L01 Main-idea inference — identify purpose from evidence rather than keyword matching.
L02 Evidence selection — choose statement best supported by passage.
L03 Meaning-in-context — infer meaning from surrounding clues.
L04 Structure-and-cohesion — determine best ordering/connection of ideas.
L05 Implicit-intent — infer speaker/writer intention.
L06 Revision-for-meaning — choose revision that improves clarity/precision.

### GENERAL KNOWLEDGE / PROBLEM SOLVING
G01 Verified-fact application — use a known fact in a new context.
G02 Source-evaluation — judge conflicting information using source quality/date/evidence.
P01 Feasibility check — determine whether a plan satisfies all constraints.
P02 Strategy selection — compare possible approaches before acting.
P03 Trade-off decision — choose best option under competing objectives.
P04 Resource allocation — distribute limited resources according to stated priorities.

## Forbidden use
An item model is not a template. The same model must not dominate a set, and adjacent sets must vary model + scenario + information structure. Cosmetic renaming or number substitution is never sufficient.
