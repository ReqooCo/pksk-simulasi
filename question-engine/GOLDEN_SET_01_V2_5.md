# SET 01 V2.5 — GOLDEN CANDIDATE

Status: CONTROLLED REFERENCE / NOT LIVE

## Purpose
V2.5 is the current controlled reference candidate for building and auditing subsequent sets. It must not be treated as an official KPM/PKSK question bank.

## Locked controls
- 100 scored items.
- 4 unique options per item.
- Valid answer index for every item.
- Exact normalized stem duplicate check passed.
- Semantic/reasoning overlap pass was performed; six materially overlapping items were rewritten before this checkpoint.
- Language-item model concentration was diversified; the previous L01 concentration was removed.
- Answer-position balance is exactly A=25, B=25, C=25, D=25.
- Option rotation is presentation balancing only and is not counted as substantive item diversity.
- Item fingerprints describe substantive content and are retained across answer-position balancing.

## Coverage snapshot
- Planned difficulty: L2=56, L3=44.
- Item models are distributed across EQ/SQ/SSQ, Mathematics, Science, IQ/Logic, BM/English, General Knowledge and Problem Solving.

## Production rule for Set 02+
Every new item must be compared against this reference on:
1. lexical similarity
2. semantic/problem similarity
3. reasoning-structure similarity
4. scenario/stimulus family
5. item-model concentration
6. difficulty/cognitive distribution

Cosmetic changes (names, numbers, answer order, superficial paraphrase) do not qualify as new items.

## Psychometric limitation
This candidate has not been empirically validated with a sufficiently large response sample. Difficulty, discrimination and distractor performance must be measured after real users attempt the items.

## Release rule
Do not replace the live bank until the content-owner review is complete. Use this candidate as the cross-set baseline for Set 02.
