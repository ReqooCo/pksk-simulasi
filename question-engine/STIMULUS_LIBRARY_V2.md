# REQOO PKSK — STIMULUS LIBRARY V2

Purpose: create purposeful context that supplies information needed for reasoning. Context is rejected when decorative.

## Stimulus families
- short notice / memo
- timetable / schedule
- price list / budget table
- measurement table
- experiment observation table
- simple graph / chart
- map / route description
- room / object arrangement
- sequence of events
- team roles / constraints
- short dialogue
- short passage
- digital-information scenario
- resource allocation table

## Stimulus construction rules
1. Every included detail must have a reason to exist.
2. At least one required inference must depend on the stimulus for L2+ items.
3. Do not repeat the same stimulus skeleton with only names/numbers changed.
4. A visual must never reveal the answer directly.
5. If multiple items share a stimulus, each must use a different reasoning path.
6. Avoid unnecessary reading load that does not increase construct validity.

## Red flags
- decorative school-event filler
- unrelated names/groups/locations
- answer stated in the stimulus
- explanation wording copied into stimulus
- repeated "Kumpulan anda perlu..." boilerplate
- same table shape with only values changed
- context that can be removed without changing the item
