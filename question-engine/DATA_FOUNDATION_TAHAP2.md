## Source handling
GREEN = factual/topic knowledge suitable for generation after verification.
YELLOW = useful concept/example but requires rewrite and/or verification.
RED = corrupted/generated legacy wording, duplicate, answer leak, unexplained ambiguity, or source whose correctness is uncertain.

## Tahap 2 content principles
- Age appropriate for Years 4–6.
- Malaysian context where useful, but context must serve the construct.
- Difficulty comes from reasoning, not obscure facts.
- No filler context.
- No cosmetic renaming/number changes.
- No direct answer giveaway.
- No dependence on official PKSK questions; all generated items are original practice items.

## Required diversity
Across a set and across sets vary:
- topic/subtopic
- cognitive target
- scenario
- information load
- reasoning pattern
- distractor mechanism
- wording pattern
- visual/non-visual format
- answer position

## Difficulty progression
Set 01–10: Level 1 — one main relation / one-step, but still contextual and non-giveaway.
Set 11–20: Level 2 — application in new context / 1–2 steps / plausible distractors.
Set 21–30: Level 3 — 2–3 information pieces / inference / comparison / strategy selection.
Set 31–40: Level 4 — multiple constraints / trade-offs / data-spatial-logic inference.
Set 41–50: Level 5 — novel multi-step / competing hypotheses / abstraction / optimisation.

## Anti-repeat thresholds
Reject any candidate that is:
- exact duplicate;
- near-exact wording;
- same underlying problem with changed numbers/names;
- same scenario + reasoning structure;
- same data pattern;
- repeated answer logic beyond the set balance limit;
- merely a paraphrase of a prior item.

## 12 mandatory gates
1. One best answer
2. Sufficient information
